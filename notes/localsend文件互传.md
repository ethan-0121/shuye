手机和电脑互传文件，还在用微信发给自己？

尤其是 iPhone、安卓、Windows、Mac 混着用的时候，有时候为了传几个文件，还得登录账号、发消息、再下载一遍。

推荐一个免费开源工具：LocalSend。

它可以让不同设备在同一个 Wi-Fi 网络下直接互传文件，不需要注册账号，也不需要先上传到网盘。

支持：

- Windows
    
- macOS
    
- Linux
    
- Android
    
- iPhone / iPad
    

使用也很简单：

1. 两台设备安装 LocalSend。
    
2. 确保连接同一个局域网。
    
3. 打开软件，选择发送文件。
    
4. 选择接收设备，对方确认即可。
    

照片、视频、PDF、压缩包都能传。

最重要的是，它不需要经过云端中转。对于经常在手机和电脑之间传文件的人，真的可以省掉不少麻烦。

不过它只能在同一局域网内使用，不是远程网盘。
